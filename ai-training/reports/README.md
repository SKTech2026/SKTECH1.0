# Evaluation Reports

The evaluation script writes local, ignored outputs here:

- `face_evaluation_summary.json`: dataset, split, verification metrics, threshold recommendation, and timing averages.
- `threshold_sweep.csv`: accuracy, FAR, FRR, precision, recall, and confusion counts for each tested threshold.
- Optional chart images generated by the notebook.

Reports are for local analysis and panel documentation. Review them for privacy before sharing and do not include raw images or personal identifiers.
