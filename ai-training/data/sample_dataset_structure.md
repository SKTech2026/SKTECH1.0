# Sample Dataset Structure

This is a directory example only. It contains no image files:

```text
ai-training/data/raw/
  person_001/
    image_001.jpg
    image_002.jpg
    image_003.jpg
  person_002/
    image_001.jpg
    image_002.jpg
    image_003.jpg
```

Use opaque local identity labels such as `person_001` rather than names. Keep the mapping between a label and a real person outside the repository. Capture varied but consented conditions while keeping one face centered and visible in each image.
